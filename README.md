# 居家力量十二周 · 离线版

手机上可以离线使用的版本（PWA）。用 Safari 打开网址，然后选「分享 → 添加到主屏幕」，以后从主屏幕图标打开，断网也能用。

- 训练记录只存在手机上（localStorage，键名 `home-strength-12w-v1`），格式和网页版完全一样，不会上传到这个仓库。
- 从网页版迁移：在网页版点「记录 → 复制全部记录」，把内容粘贴到离线版「记录」最下面的文本框，点「用文本框里的内容恢复」。离线版里已经有记录时，会让你选合并还是替换。
- 修改任何文件后，要把 `sw.js` 里的 `VERSION` 加一，手机下次联网打开时才会换成新版本。
